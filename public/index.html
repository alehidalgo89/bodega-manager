Bodega de Candinho

Sistema de Gestión de Inventario de Vinos

✓ Servidor Activo y Funcionando

Características

  • Registro de vinos con detalles completos
  • Generación automática de códigos QR
  • Búsqueda avanzada por tipo, región y año
  • Ubicación exacta de cada botella
  • Reportes estadísticos
  • 8 zonas de almacenamiento

🔌 API Endpoints Disponibles

Obtener Países GET /api/paises
Obtener Regiones GET /api/paises/:id/regiones
Obtener Tipos de Vino GET /api/tipos-vino
Obtener Vinos GET /api/vinos
Crear Vino POST /api/vinos
Registrar Salida POST /api/vinos/:id/salida
Reportes GET /api/reportes/resumen
Movimientos GET /api/movimientos
